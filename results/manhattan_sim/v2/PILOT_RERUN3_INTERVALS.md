# Manhattan simulation: every interval with the replication as the unit of clustering: the HB runs of the code now checked out

Written by `python -m manhattan.sim.cluster_ci --current-hb` (the method is that of session "6M Manhattan C: dormancy fix and statistical checks"). **Synthetic data only. Every run here is a pilot: nothing is decided, and this file changes no pre-registered interval, threshold or verdict rule.** It shows what the same numbers look like when the small number of replications is allowed for.

## Method

- **The old interval** is the pre-registered one (SIM_PREREG.md section 4): `mean ± 1.96 · sd/√R` over per-replication values, or a percentile interval from 2,000 bootstrap resamples of whole replications. Both already treat a replication as the unit; neither allows for how few there are in a pilot.
- **The corrected interval** keeps the estimate and uses the delete-one-replication jackknife standard error of that same estimator with a Student-t quantile on `R − 1` degrees of freedom. Where no replication had an event (an interval printed as 0.000 to 0.000) it gives the exact bound over replications instead, `1 − 0.025^(1/R)`.
- **One statistic for which the correction is rough.** The expected calibration error counts a bin only once it holds 200 observations, so leaving a replication out can drop a bin and move the number in a jump. Its corrected interval is wide for that reason and says only that so few replications do not locate it.
- **Verdict** means the pilot's wording: is the judged end of the interval within or outside the threshold so far. Rows the small-groups rule leaves unevaluated (fewer than 200 observations) stay unevaluated.
- 170 intervals in 5 runs; 24 have a threshold and enough observations to be placed; **4 change side**. The corrected interval is on average 1.29 times as wide as the old one (median 1.20).
